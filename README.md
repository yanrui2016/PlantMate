# 植物养植助手

根据天气、植物品种、土壤和光照等信息，动态估算花盆中的“水分余额”；再结合 AI 图像识别，观察植物的生长状态，及时发现缺水等问题，并给出个性化养护建议。

让 PlantMate 帮你判断什么时候该浇水、浇多少水，告别凭感觉养植物，让每一次养护都更科学、更简单。

## 运行环境

- 浏览器：最新版 Chrome 或 Edge
- 不需要安装任何软件，也不需要服务器
- 天气数据：Open-Meteo（免费，无需注册）
- AI 照片识别：智谱 GLM-4.6V-Flash（免费，需要自己注册获取密钥）

## 第一次使用

1. 打开 `index.html`
2. 到"设置"选择省份和城市，点"保存城市"，再点"测试天气连接"
3. 在智谱开放平台注册并获取密钥，填到"设置"里，点"测试AI连接"
4. 回到首页，添加第一盆植物

密钥只保存在本机浏览器中，不会写进代码。

## 本地运行

直接双击 `index.html` 即可。如果 AI 识别在本地打不开，可以在这个文件夹里运行一个本地小服务器：

```
python -m http.server 8000
```

然后在浏览器打开 http://localhost:8000

## 部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，把这个文件夹里的所有文件上传
2. 进入仓库的 Settings → Pages
3. Source 选择 "Deploy from a branch"，分支选 main，文件夹选 /(root)，保存
4. 等一两分钟，页面上会显示网址

注意：在线版和本地版的数据互不相通（浏览器按网址分别保存数据）。

## 演示模式

在"设置"里打开"演示模式"后，天气和照片识别都使用预先准备好的数据，不需要联网。拍照诊断时可以选择演示场景。

## 文件说明

| 文件 | 作用 |
|---|---|
| index.html | 首页：天气、今日提醒、我的植物 |
| add.html | 添加和修改植物 |
| detail.html | 植物详情：水分、建议、浇水、测土、折线图、记录 |
| diagnose.html | 拍照诊断：拍照 → 确认观察结果 → 查看建议 |
| settings.html | 设置：城市、AI 密钥、演示模式、数据备份、高级设置 |
| css/style.css | 统一的视觉风格 |
| js/config.js | 参数配置：植物习性表、土壤参数、各种系数 |
| js/storage.js | 本地存储：读写数据、导出导入 |
| js/weather.js | 天气：获取历史天气和预报 |
| js/cities.js | 全国省份和城市列表 |
| js/water.js | 水分计算（计算层） |
| js/update.js | 每日更新：补算没打开的天数 |
| js/judge.js | 综合判断（判断层）：按规则给出建议 |
| js/vision.js | 照片识别：调用智谱并检查答案 |
| js/demo.js | 演示模式 |
| js/ui.js | 界面小工具：导航栏、弹窗、图标 |

## 核心公式

今日消耗 = 基础消耗15% × 植物系数 × 温度系数 × 湿度系数 × 光照系数 × 土壤系数

计算方法参考联合国粮农组织《FAO-56 作物蒸散量》，针对盆栽植物做了简化。所有系数都是初始值，可在"高级设置"中调整。
